# Java + Spring Boot Roadmap 🚀

Meu plano de estudos para evoluir do básico de Java ao desenvolvimento de APIs REST profissionais com Spring Boot.

## 🎯 Objetivo

Desenvolver competências em Java, backend, bancos de dados, testes, segurança, arquitetura e deploy, construindo projetos práticos ao longo de 36 semanas.

## 📅 Plano de estudos

- **Duração:** 36 semanas
- **Rotina:** 1h30 a 2h por dia, de segunda a sexta
- **Método:** teoria, prática, revisão e projetos
- **Versionamento:** Git e GitHub

## 🗺️ Etapas do roadmap

- [ ] **Fase 1 — Semanas 1–4:** lógica e fundamentos de Java
- [ ] **Fase 2 — Semanas 5–8:** orientação a objetos e Java intermediário
- [ ] **Fase 3 — Semanas 9–10:** Git, Maven, HTTP e APIs REST
- [ ] **Fase 4 — Semanas 11–14:** primeiros passos com Spring Boot
- [ ] **Fase 5 — Semanas 15–18:** SQL, PostgreSQL e JPA
- [ ] **Fase 6 — Semanas 19–22:** DTOs, validação e testes
- [ ] **Fase 7 — Semanas 23–26:** Spring Security e JWT
- [ ] **Fase 8 — Semanas 27–31:** performance, cache, Docker e CI/CD
- [ ] **Fase 9 — Semanas 32–36:** arquitetura, observabilidade e portfólio

## 🛠️ Projetos práticos

- [ ] **1. Calculadora em Java**
- [ ] **2. Sistema de cadastro com orientação a objetos**
- [ ] **3. API REST de tarefas com Spring Boot**
- [ ] **4. API de produtos com PostgreSQL e JPA**
- [ ] **5. Sistema de pedidos com autenticação, testes, Docker e deploy**
